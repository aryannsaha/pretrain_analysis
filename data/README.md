# Data

Large datasets are intentionally ignored by Git.

- `raw/`: original trajectory or source files.
- `interim/`: temporary conversions or filtered intermediate files.
- `processed/`: workflow-ready datasets.
- `splits/`: train/validation/test split metadata or split directories.

Suggested workflow-specific subfolders:

- `data/processed/uma/`
- `data/processed/upet/`
- `data/processed/mace/`
